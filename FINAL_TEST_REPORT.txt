🏗️ SYSTEM ARCHITECTURE - VERIFIED & WORKING

INPUT
  ↓
INGESTION (Port 8001)
  • Parses: Text DPR, Voice transcripts, Spreadsheets, PDFs, Scans
  • Extracts: Structured events via Ollama Qwen3-4B (or offline fallback)
  • Returns: ExtractedEvent[] with confidence scores
  ↓
MATCHING (Port 8002)
  • Loads: L6 Primavera schedule (CSV format)
  • Indexes: FAISS vector store with Sentence-BERT embeddings
  • Matches: Semantic similarity + deterministic tag matching
  • Returns: MatchResult[] with top-3 ranked alternatives
  ↓
PLANNER REVIEW (UI)
  • Reviews: Extracted events & top-3 alternatives
  • Decides: Accept/Reject/Correct match
  ↓
WRITEBACK (Port 8003)
  • Logs: Approval/rejection to SQLite audit table
  • Records: User, timestamp, confidence, source
  • Persists: Full audit trail for compliance
  ↓
ANALYTICS (Port 8004)
  • Queries: DuckDB institutional memory warehouse
  • Aggregates: Daily progress, discipline stats, delays
  • Serves: S-curves, confidence metrics, reports
